## Featured project

### [Cybersecurity Project Portfolio](https://github.com/NAYEM00000/-cybersecurity-project-portfolio)

A collection of seven Python command-line projects focused on defensive security practice:

| Project | What it does |
|---|---|
| [Password Security Analyzer](https://github.com/NAYEM00000/-cybersecurity-project-portfolio/tree/main/password-security-analyzer) | Gives basic password feedback and generates passwords locally. |
| [Web Security Header Checker](https://github.com/NAYEM00000/-cybersecurity-project-portfolio/tree/main/web-security-header-checker) | Checks common HTTP security headers and cookie flags. |
| [Authentication Log Analyzer](https://github.com/NAYEM00000/-cybersecurity-project-portfolio/tree/main/authentication-log-analyzer) | Reviews sample authentication logs for repeated failed sign-ins. |
| [Network Traffic Anomaly Detector](https://github.com/NAYEM00000/-cybersecurity-project-portfolio/tree/main/network-traffic-anomaly-detector) | Examines exported flow records for unusual byte counts and destination-port patterns. |
| [Phishing URL Risk Analyzer](https://github.com/NAYEM00000/-cybersecurity-project-portfolio/tree/main/phishing-url-risk-analyzer) | Scores URL characteristics offline without opening the link. |
| [File Integrity Monitor](https://github.com/NAYEM00000/-cybersecurity-project-portfolio/tree/main/file-integrity-monitor) | Uses SHA-256 hashes to report added, changed, and removed files. |
| [TLS Certificate Inspector](https://github.com/NAYEM00000/-cybersecurity-project-portfolio/tree/main/tls-certificate-inspector) | Connects to a host and reports details about its verified TLS certificate. |

## A note on my projects

These projects are learning exercises and are intended for authorized, defensive use. Sample log and traffic data are synthetic. Their results are indicators for practice, not proof of compromise or a substitute for a professional security assessment.

I'm learning as I build, and I’ll keep improving the code, tests, and documentation over time.
